# Roadmap

## Vertical slices

1. **MVP shell** — dashboard, learning path, local lesson completion, and one validated chapter.
2. **Lesson reader** — render paragraph, rule, example, table, and source references from chapter JSON.
3. **Practice engine** — independent tagged question bank, one-question flow, explanations, and attempt history.
4. **Flashcards** — due queue, confidence rating, and local review scheduling.
5. **Exam simulations** — TFLM blueprint, timer, submission report, and topic breakdown.
6. **Data portability** — progress export/import and explicit local-storage recovery guidance.

Content quality should be validated before adding more gamification or exam modes.
