# Orthly documentation

Orthly is a French-learning workspace for UQAR course material and TFLM preparation. The MVP is intentionally static: lessons and exercises are versioned JSON files, while personal progress is stored in the browser.

- [Progress architecture](./progress-architecture.md) — localStorage state, scoring, and review recommendations.
- [Exam architecture](./exam-architecture.md) — timed simulation behavior and exam blueprints.
- [Design system](./design-system.md) — visual language, responsive layout, and accessibility rules.
- [Roadmap](./roadmap.md) — vertical slices that build on the MVP.
