# Design system

## Direction

Orthly is playful enough to invite daily practice and restrained enough for serious exam preparation. It takes inspiration from short learning loops and visible progress without copying another product's brand, mascot, or illustrations.

## Tokens

- Primary green `#58CC02`: learning actions and completion.
- Dark green `#46A302`: pressed button state.
- Deep navy `#172B4D`: text and headings.
- Light background `#F7F9FC`: application canvas.
- Blue `#1CB0F6`: information and progress.
- Purple `#CE82FF`: milestones and achievements.
- Orange `#FF9600`: streaks and reminders.
- Red `#FF4B4B`: errors and mistakes.

## Layout

Desktop uses a persistent sidebar, central work area, and optional study panel. Mobile collapses navigation and keeps exercise actions within reach. Cards have rounded corners, clear borders, soft shadows, and one dominant action.

## Accessibility

Use semantic headings, visible keyboard focus, minimum comfortable touch targets, readable contrast, and `prefers-reduced-motion`. Color must not be the only indicator of state. French content uses `lang="fr-CA"`.
